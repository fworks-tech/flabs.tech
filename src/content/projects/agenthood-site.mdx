## Overview

The public face of Agenthood — an AI engineering team that earns every merge. It hosts the homepage, documentation, Academy, and the browser-based Studio where the team runs autonomously with every decision auditable, plus a scheduled news digest that ships via automated release PRs. Fast, SEO-tuned, and deployed at [agenthood.flabs.tech](https://agenthood.flabs.tech).

**Stack:** Next.js · TypeScript · React · SEO tooling

**Links:** [agenthood.flabs.tech](https://agenthood.flabs.tech) · [GitHub](https://github.com/fworks-tech/agenthood-site)

## Highlights

- **Landing & docs** — project showcase, member docs, and playground entry point for the Agenthood runtime
- **Automated news digest** — a scheduled GitHub Action drafts release digests in the house style, validates them against a strict contract, and opens a PR for review
- **SEO-first** — structured metadata and fast static rendering on the Next.js App Router
