## Overview

Atlaslink is a multi-agent orchestrator and Agenthood proof of concept — a modern UI for connecting and running AI agents through live diagram flows. Agents are wired together visually and executed as a pipeline: design the flow, run it, and watch each node produce its result in real time.

**Links:** [atlas.flabs.tech](https://atlas.flabs.tech) · [GitHub](https://github.com/fworks-tech/atlaslink)

## Features

- Visual diagram editor for wiring agents into executable pipelines and workflows.
- Live flow runs with per-node results streamed in real time.
- Agenthood-compatible orchestration primitives (nodes, edges, run pipeline).

## Stack

TypeScript, React flow-based UI, Agenthood orchestration concepts, deployed at atlas.flabs.tech.

Live in production at [atlas.flabs.tech](https://atlas.flabs.tech) — the repository and live app are public, with news and updates published via the GitHub repository.
