## Overview

Atlaslink is an experimental shared workspace where people and AI agents work through tasks together. Built on [Agenthood](https://github.com/fworks-tech/agenthood) — the core/runtime agents run on — Atlaslink is the shared room where people follow progress, steer execution, and make decisions alongside those agents: delegate work, watch it happen, step in when a decision is needed.

**Links:** [atlas.flabs.tech](https://atlas.flabs.tech) · [GitHub](https://github.com/fworks-tech/atlaslink)

## Features

- Shared live sessions — humans and agents in one room, with presence, typing indicators, and delivery receipts.
- Steer mid-flight — redirect a running session, rewrite a queued prompt, or interrupt entirely.
- Approval gates — parked questions wait on a human; approve, reject, or reply in place.
- Per-project sharing — members, roles, and single-use invite links instead of tenant-wide access.
- Session activity on record, with LLM spend rolled up per agent, per day.

## Stack

TypeScript, Fastify daemon + Next.js dashboard, SQLite/Postgres event store, Server-Sent Events rooms, deployed at atlas.flabs.tech.

## Status

Experimental proof of concept, live as a demo at [atlas.flabs.tech](https://atlas.flabs.tech) — the repository and live app are public, with news and updates published via the GitHub repository.
