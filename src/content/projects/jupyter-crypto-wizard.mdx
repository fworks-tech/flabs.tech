## Overview

Jupyter Crypto Wizard is a self-contained intelligence workspace for cryptocurrency market analysis. Built with Streamlit and Python 3.11, it consolidates the data feeds, analytics, and alerts that traders typically juggle across multiple tools into a single dashboard.

**Stack:** Python 3.11 · Streamlit · Plotly · pandas · Jupyter · MIT License

## Features

- **KPI Dashboard** — Real-time price, volume, market cap, and dominance metrics across major assets
- **Trend Analysis** — Moving averages, RSI, MACD, and Bollinger Bands with interactive Plotly charts
- **Risk Panels** — Portfolio correlation heatmaps and volatility surface visualization
- **Alert System** — Threshold-based price and volume alerts with configurable triggers
- **Newsletter Flows** — Automated digest generation from daily market data summaries

## Design Approach

Built as a Jupyter-native project: the exploration, visualization, and reporting pipelines live in the same environment. The Streamlit layer wraps the notebook logic in a shareable web UI without requiring a separate backend.

The alert system uses a simple polling loop with configurable cooldowns — no external queue required for personal use. Newsletter flows output structured Markdown that can be piped to any delivery service.
