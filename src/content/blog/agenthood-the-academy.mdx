In **9 articles**, you will:

- Understand how LLMs work
- Understand how RAG works
- Learn how to write prompts that are clear, useful, and reliable.

### Level 2 — AI Agent Essentials

- Be ready to plan actions and design around those failure modes.

### Level 3 — Advanced Agent Skills

In **5 articles**, you will:

- Learn how to ship agents into production and operate them safely.
- See how to keep them healthy over time.

## Where to start

- Start with **Level 1** if you are new to GenAI.
- Start with **Level 2** if you already understand the basics.
- Complete **all 3 levels** if you are building for production.
