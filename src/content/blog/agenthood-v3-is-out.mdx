## What shipped

### HierarchicalChunkStrategy

Two new chunking strategies that understand document structure instead of treating everything as a flat array of tokens:

- **MarkdownHierarchicalChunkStrategy** — parses H1/H2 headings as parent sections, paragraphs as child chunks. Retrieval can target a precise paragraph and automatically resolve its parent section for context.
- **CodeHierarchicalChunkStrategy** — parses top-level declarations (classes, functions, interfaces) as parent blocks with their inner code as children. Uses Tree-sitter for deterministic AST parsing.

Both strategies produce `ParentChunk` and `ChildChunk` types. The Indexer stores parent content atomically; the Retriever resolves parents with a 30-second TTL cache.

### AgenticRAG

Not every query needs a vector search. AgenticRAG wraps the Retriever with a classifier that decides the strategy based on keyword analysis:

- **skip** — the agent already knows the answer (requires 2+ word overlap with short-term memory)
- **vector** — semantic similarity search only
- **graph** — Knowledge Graph traversal (falls back to vector when no KGS is configured)
- **both** — parallel vector + graph with results merged

Provenance tracking captures the chosen strategy, match count, graph hop depth, and source paths.

### MemberOrchestrator

The Society now detects which member should handle a given task without being told. `MemberTriggers` defines keyword patterns, file globs, and stage mappings for all 14 members. `detectMembers()` scores each member against the input with a threshold of 2+.

The `--detect` flag on the CLI runs detection before any LLM call — no API key needed for routing decisions.

### OpenCode Zen + Go providers

Agenthood now ships with first-class support for OpenCode:

- **OpenCode Zen** — pay-as-you-go at [`api.opencode.ai/zen/v1`](https://api.opencode.ai/zen/v1)
- **OpenCode Go** — subscription at [`api.opencode.ai/zen/go/v1`](https://api.opencode.ai/zen/go/v1), defaults to `deepseek-v4-flash` ($0.14/$0.28 per 1M tokens)

Both are OpenAI-compatible. The provider includes a `toOpenAIMessages` converter that handles DeepSeek's tool format requirements (snake_case `tool_calls`, correct `tool_call_id` ordering). Set `OPENCODE_API_KEY` in your environment and pass `--provider opencode` or `--provider opencode-go`.

### Governance docs

Two new documents in `governance/`:

- **[member-map.md](https://github.com/fworks-tech/agenthood/blob/main/governance/member-map.md)** — RACI matrix for all 14 members plus 3 planned M6 roles
- **[release-policy.md](https://github.com/fworks-tech/agenthood/blob/main/governance/release-policy.md)** — change approval rules, version numbering, breaking change announcements, deprecation policy, compliance

### CI improvements

- Shared composite action (`.github/actions/agent-analysis/`) eliminates duplicated agent analysis blocks across 3 workflows
- `continue-on-error` with separate stderr capture — agent failures are visible, not silently swallowed
- File capping (10 files max) and API key guards keep costs at ~$0.01 per run
- Gitleaks pinned to a specific commit SHA
- `npm audit` added to 3 workflows
- All `gh` commands now have explicit `GITHUB_TOKEN` auth
