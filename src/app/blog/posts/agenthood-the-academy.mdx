## Why I'm building a curriculum

When I started building Agenthood, the goal was simple: encode engineering standards as executable agents so I'd stop skipping code reviews at 2am under deadline pressure. What I didn't expect was how deep the rabbit hole goes.

Building a production-grade multi-agent framework forced me to understand things I thought I knew: how memory actually works under token pressure, why naive RAG implementations hallucinate confidently, what "ReAct" means beyond the paper, and how to make agents fail gracefully instead of silently going off the rails.

I wrote all of this down in scattered notes. **The Academy** is the project to turn those notes into 25 publishable articles — each concept mapped directly to Agenthood's source code so you can read the theory and immediately trace it to a working implementation.

---

## Three levels, 25 articles

The curriculum follows a deliberate progression:

### Level 1 — GenAI & RAG Basics (9 articles)

The foundation. No prior AI experience assumed. This covers:

- What language models actually do (and what they can't)
- Prompt engineering that holds up in production, not just demos
- Embeddings and vector search without the magic-box explanation
- Building your first RAG pipeline step by step
- Why chunking strategy matters more than people admit
- Evaluating RAG output — hallucination rate, relevance, groundedness
- Token budgets: what they are and why you will run out at the worst time
- When to retrieve and when not to (Agentic RAG vs pipeline RAG)
- Semantic search vs keyword search — when to use which

### Level 2 — AI Agent Essentials (11 articles)

This is where most "AI developer" guides stop being useful. The gap between "I can call the Claude API" and "I can ship a production agent" is enormous. This level covers the gap:

- The ReAct reasoning loop — Reason, Act, Observe, repeat
- Tool use: how agents decide what to call and when to stop
- Memory architecture: the four tiers and why you need all of them
- Short-term context management under compression pressure
- Planning with goal chains and multi-step task decomposition
- Error recovery — retry policies, fallback strategies, human escalation
- The Orchestrator pattern: routing tasks to specialized agents
- Safety guards: sandboxing tools, validating outputs, rate limiting
- From single agent to multi-agent: when the overhead is worth it
- Evaluating agents — metrics beyond "did it answer the question"
- Debugging agents — the five-step protocol Agenthood uses

### Level 3 — Advanced Agent Skills (5 articles)

The frontier. This is what I'm building in Agenthood v2.x:

- Hierarchical parent-child chunking for precision RAG
- Knowledge Graph retrieval alongside vector search
- Dynamic model routing by query complexity (cheap model by default, expensive only when needed)
- Society self-awareness: how agents query the collective institutional memory
- EpisodeLearner: closing the self-improvement loop with eval → memory → better responses

## Why this exists

Solo engineering tends to drift. The same applies to learning — without a structured map, you end up with swiss-cheese knowledge, deep in one area and completely blank in others. The Academy is my attempt to build the structured roadmap I wish existed when I started building Agenthood.

Every article will be:
- **Code-grounded**: concepts traced to actual Agenthood source, not pseudocode
- **Honest about tradeoffs**: no "just use RAG" handwaving
- **Portable**: the skills are framework-agnostic even though the examples use Agenthood

The milestone ships September 2026. Articles will be published here as they're written.
