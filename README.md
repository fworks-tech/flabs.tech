## Stack

- [Next.js](https://nextjs.org) 16 (App Router) + [Once UI](https://once-ui.com) design system
- TypeScript · MDX for blog & projects
- Deployed on [Vercel](https://vercel.com)

---

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
